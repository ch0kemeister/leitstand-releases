# Leitstand — Releases

Fertige macOS-Builds von **Leitstand**, einem Manager für Claude-Code-/Codex-Instanzen.
Dieses Repo enthält nur die veröffentlichten App-Pakete; die App aktualisiert sich
darüber selbst (Einstellungen → Updates).

## Installation

1. Unter [Releases](../../releases/latest) die Datei `Leitstand_<version>_universal.dmg` laden
   (läuft auf Apple Silicon und Intel).
2. Leitstand in den Programme-Ordner ziehen.
3. Beim **ersten** Start: Rechtsklick auf die App → „Öffnen" (die App ist nicht notarisiert).
4. In Leitstand unter Einstellungen „Hooks installieren" klicken (Statuserkennung).

Voraussetzung: installiertes und angemeldetes [Claude Code](https://claude.com/claude-code).
